# Feedback Collector (Demo)

This example project shows a simple two-step workflow:

1. **New Feedback** — A tray where raw customer feedback cards land. A person reviews each one and marks it ready.
2. **Summarize & Tag** — An AI worker reads each feedback card and writes a one-sentence summary plus a sentiment tag (positive / neutral / negative).

## How to use this demo

1. Open the **New Feedback** tray and create a new card with some customer feedback text.
2. Mark the card **Ready** to send it to the worker.
3. Open **Summarize & Tag** and click **Run now** to process the card.
4. The output card lands back in the tray with the summary and tag added.

You can edit the worker's process instructions to change how it summarizes or what tags it uses.
